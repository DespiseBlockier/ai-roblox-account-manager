# Reference source review

Reference: [ic3w0lf22/Roblox-Account-Manager](https://github.com/ic3w0lf22/Roblox-Account-Manager), source commit **c2b13d146d5db609d499870145e8d2dff2506581**. A read-only source checkout is under the workspace's `.reference/Roblox-Account-Manager`. No original executable, release archive, installer, or third-party source from that checkout was executed or incorporated into this app.

This was a focused review of the account/session, launch, storage, updater, network-control, and browser code, plus the main UI and README. It is not a full forensic audit of every dependency, historical version, or release artifact. Finding a security-sensitive feature is not evidence of intentional malware. The checked-in source alone cannot establish that distributed binaries match it.

## Findings that informed this implementation

| Source area | Observed behavior | Replacement decision |
| --- | --- | --- |
| `Forms/Updater.cs`, `AccountManager.cs`, `Classes/Program.cs` | Checks GitHub release metadata, downloads update archives, replaces files, and starts the updated program. The reviewed update flow did not independently verify a publisher signature against a pinned trust key before execution. | No updater or executable downloads. Build this app locally and review changes manually. |
| `AccountManager.cs` request dispatcher and `Classes/WebServer.cs` | Optional HTTP listener with account-control and credential-related methods, governed by configuration and password checks. Can be configured to bind beyond localhost. | No HTTP listener or network control API. |
| `Nexus/AccountControl.cs`, `Nexus/WebsocketServer.cs` | Optional WebSocket account-control server; configuration can bind to all interfaces. | No WebSocket server or account-control endpoint. |
| `Classes/AccountBrowser.cs` | Login automation, optional CAPTCHA-service calls, request monitoring, password/cookie handling, and configurable post-navigation scripts. | User-driven verification and fixed login autofill. v1.2 adds an explicitly started browser-code editor with completion/cancellation controls and independently confirmed group membership; code is never automatically downloaded or loaded after login. No CAPTCHA service or password-field capture. |
| `Classes/Account.cs` and account context menus | Stores account security token and password fields; includes authentication-ticket and cookie-related utilities and account-changing API functions. | v1.3 saves explicitly supplied passwords and verified cookies in a portable master-password-encrypted vault. No credential clipboard export or automatic account-credential changes. Identity checked before managed actions. |
| Account persistence in `AccountManager.cs` | Supports several encrypted persistence paths, optional password encryption, and an explicitly named opt-out file for unencrypted storage. | Portable AES-256-GCM vault and authenticated layout exports, no plaintext mode. Windows DPAPI is retained only for explicitly importing older local vaults. Clean release ZIPs exclude account data. |
| `Classes/RobloxProcess.cs` and related utilities | Watcher behavior, downloaded matching rules, and process/handle utilities. | No process watcher, downloaded rules, process termination, handle manipulation, or client patching. |
| Main WinForms UI | Account list, groups, alias/description fields, game and Job ID inputs, browser and join actions, favorites/recent games, and public server browsing. | Reimplemented these core workflows in a smaller native WPF app. Private server links use Roblox's own Play flow. |

The new application has one application package dependency, Microsoft's WebView2 SDK. The .NET SDK also restores its ILLink build tools for single-file analysis; these tools are not shipped as an application dependency. Cryptography, HTTP, JSON, and UI use .NET/Windows APIs. Dependency versions and package hashes are recorded in the generated NuGet lockfile. See `SECURITY.md` for the remaining risks and the exact test scope.
